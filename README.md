# Training-Management-System-TMS-
ACE_For Academy TMS MVP is a desktop-first Training Management System that centralizes trainers, OEM certifications, customers, requirements, allocations, workshop dashboards, feedback, analytics, and admin controls. 

## Services

| Directory | Description |
| --- | --- |
| [`tms-core-service`](./tms-core-service) | Training Management Core Service (Spring Boot) |
| [`tms-outbox-service`](./tms-outbox-service) | Outbox Processing Service (Spring Boot) |
| [`tms-frontend-app`](./tms-frontend-app) | Frontend SPA (React + Vite), story `SCAFFOLD-frontend-app` |
